Sail Into Shadow
เกม Adventure 2D พัฒนาโดย Unity

พัฒนาโดย
นายหยี้วเฉิง โลว์ (เขียนโค้ด dialogue และสกิลของ Player)
นายชานนท์ สูงสันเขต (เขียนโค้ด Parallax background การเปลี่ยนฉากเมนูเริ่มเกม และวาดกราฟิกเกม)
นายฐานวัฒน์ รัชธนันพงศ์ (เขียนโค้ด AI ศัตรูและสกิลของ Boss)

ภาพรวมเกม
Genre : Adventure RPG
Platform : PC
เครื่องมือพัฒนา : Unity 6.3 LTS (6000.3.10f1)
Language : C#
IDE : Visual Studio Code

ระบบเกม
ระบบ ผู้เล่นการเคลื่อนที่ การกระโดด การ dash สกิลการโจมตีต่างๆ
ระบบ บอส มีการเคลื่อนตามติดตามผู้เล่นมีการโจมตี และการเปลี่ยนสถานะโจมตี ตามสกิลต่างๆ
ระบบ ฟื้นฟูพลังชีวิต มีการดรอปพลังงานชีวิตให้ผู้เล่นได้เก็บหลังจากเอาชนะศัตรูลูกน้องซึ่งมีเวลาให้เก็บก่อนจะหายไปเอง
ระบบ ศัตรูลูกน้อง มีการติดตามเคลื่อนที่ตามผู้เล่นโจมตีผู้เล่นและดรอปพลังชีวิตให้เก็บได้เป็นเวลาสั้นๆ
